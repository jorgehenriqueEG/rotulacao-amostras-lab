# Rotulacao Amostras Lab
## Descrição do Problema
Gerenciar o estoque de frascos de reagentes químicos em um laboratório de microbiologia, verificando validade e criticidade de armazenamento.
## Requisitos
- Calcular dias restantes até a validade
- Marcar como 'CRITICO' se faltar menos de 30 dias
- Sugerir descarte se estiver vencido
## Exemplo de Uso
Entrada: Lista de reagentes com nome e data de validade.
Saída: Relatório com status de cada frasco.
